# Partner Readiness

This repository is a simulation-only HRM photonic AI planning toolkit. It is
ready for external review and partner discussion, but it is not hardware
evidence.

It does not claim hardware validation, foundry calibration, measured transfer
matrices, production inference readiness, real hardware latency, real hardware
energy efficiency, physical accuracy, quantum advantage, hardware-native
intelligence, or power-free computation.

## What The Repo Can Do Today

- Regenerate deterministic simulation reports.
- Classify model layers as abstract HRM-mappable, classical, or unsupported.
- Rank deterministic model fixtures for simulation-only planning.
- Estimate parametric scenario and requirement envelopes.
- Build an error budget from simulation reports.
- Keep Stage 5, Stage 6, and Stage 7 blocked until real external evidence is
  supplied.

## What Is Simulation-Only

- Abstract matrix mapping.
- Rectangular and complex/unitary simulation support.
- Perturbation sweeps.
- Synthetic calibration.
- Model suitability and portfolio ranking.
- Hardware scenario and requirement estimates.
- Synthetic transfer-matrix ingestion sandbox.

## Missing Hardware Evidence

- Foundry calibrated device model.
- Measured HRM transfer matrix.
- End-to-end hardware inference benchmark.

## Partner Types To Approach

- Photonic test-lab partner.
